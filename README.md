# 🌱 Hydroponic Monitoring & Automation System

A modern, smart hydroponic system project designed to monitor plant growth environments, track nutrient levels, and automate watering and lighting schedules for optimal crop yield.

---

## ✨ Features

- **Real-Time Sensor Monitoring:** Track vital parameters including pH levels, TDS/EC (Total Dissolved Solids), water temperature, and water level.
- **Automated Control:** Automated nutrient dosing and water pump cycles based on pre-set configurations.
- **Responsive Dashboard:** Clean and intuitive user interface for monitoring system stats and adjusting settings.
- **Data Logging:** Record historical sensor data to analyze plant health over time.

---

## 🛠️ Tech Stack

- **Frontend / Dashboard:** HTML, CSS, JavaScript / React.js
- **Microcontroller / IoT:** ESP32 / Arduino (or compatible IoT modules)
- **Sensors:** pH Sensor, TDS Meter, DS18B20 (Water Temperature), Ultrasonic/Water Level Sensor
